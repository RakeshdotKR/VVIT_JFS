Step 2: Create Tables with Keys & Constraints
1. departments Table
Stores corporate divisions across Indian tech hubs.
CREATE TABLE departments (
    dept_id INT AUTO_INCREMENT,
    dept_name VARCHAR(50) NOT NULL,
    city VARCHAR(50) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    -- Constraints
    CONSTRAINT pk_departments PRIMARY KEY (dept_id),
    CONSTRAINT uq_dept_name UNIQUE (dept_name)
);
________________________________________
2. employees Table
Stores workforce records with validation checks, a foreign key referencing departments, and a self-referencing foreign key for hierarchy/managers.
CREATE TABLE employees (
    emp_id INT AUTO_INCREMENT,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL,
    phone_number VARCHAR(15) NOT NULL,
    hire_date DATE NOT NULL,
    job_title VARCHAR(50) NOT NULL,
    salary DECIMAL(10, 2) NOT NULL,
    dept_id INT,
    manager_id INT,
    status ENUM('Active', 'On Leave', 'Resigned') DEFAULT 'Active',

    -- Constraints
    CONSTRAINT pk_employees PRIMARY KEY (emp_id),
    CONSTRAINT uq_emp_email UNIQUE (email),
    CONSTRAINT uq_emp_phone UNIQUE (phone_number),
    CONSTRAINT chk_emp_salary CHECK (salary >= 25000.00), -- Minimum salary constraint
    
    -- Foreign Keys
    CONSTRAINT fk_emp_department 
        FOREIGN KEY (dept_id) REFERENCES departments(dept_id) 
        ON DELETE SET NULL 
        ON UPDATE CASCADE,
        
    CONSTRAINT fk_emp_manager 
        FOREIGN KEY (manager_id) REFERENCES employees(emp_id) 
        ON DELETE SET NULL 
        ON UPDATE CASCADE
);
________________________________________
3. projects Table
Stores enterprise projects, assigned budgets in INR, and department associations.
CREATE TABLE projects (
    project_id INT AUTO_INCREMENT,
    project_name VARCHAR(100) NOT NULL,
    budget DECIMAL(12, 2) NOT NULL,
    start_date DATE NOT NULL,
    end_date DATE,
    dept_id INT,

    -- Constraints
    CONSTRAINT pk_projects PRIMARY KEY (project_id),
    CONSTRAINT uq_project_name UNIQUE (project_name),
    CONSTRAINT chk_project_budget CHECK (budget > 0),
    CONSTRAINT chk_project_timeline CHECK (end_date IS NULL OR end_date >= start_date),

    -- Foreign Key
    CONSTRAINT fk_project_department 
        FOREIGN KEY (dept_id) REFERENCES departments(dept_id) 
        ON DELETE RESTRICT 
        ON UPDATE CASCADE
);
________________________________________
4. employee_projects (Junction Table)
Implements a many-to-many ($M:N$) mapping between employees and projects using a Composite Primary Key.
CREATE TABLE employee_projects (
    emp_id INT NOT NULL,
    project_id INT NOT NULL,
    assigned_role VARCHAR(50) DEFAULT 'Contributor',
    assigned_date DATE NOT NULL,
    hours_allocated INT DEFAULT 40,

    -- Composite Primary Key (prevents assigning the same employee twice to the same project)
    CONSTRAINT pk_emp_proj PRIMARY KEY (emp_id, project_id),
    CONSTRAINT chk_hours CHECK (hours_allocated > 0 AND hours_allocated <= 60),

    -- Foreign Keys
    CONSTRAINT fk_ep_employee 
        FOREIGN KEY (emp_id) REFERENCES employees(emp_id) 
        ON DELETE CASCADE 
        ON UPDATE CASCADE,

    CONSTRAINT fk_ep_project 
        FOREIGN KEY (project_id) REFERENCES projects(project_id) 
        ON DELETE CASCADE 
        ON UPDATE CASCADE
);

2. SELECT Operations (Read)
A. Basic Projection with Calculated/Aliased Columns
Computes annual CTC (Cost to Company) and a projected 10% appraisal for each engineer.
SELECT 
    emp_id AS 'Employee ID',
    CONCAT(first_name, ' ', last_name) AS 'Full Name',
    job_title AS 'Role',
    salary AS 'Monthly Salary',
    (salary * 12) AS 'Annual CTC (INR)',
    ROUND(salary * 1.10, 2) AS 'Salary Post 10% Hike'
FROM employees
WHERE dept_id = 10;
B. Eliminating Duplicates using DISTINCT
Retrieves unique job roles currently held across all branches.
SELECT DISTINCT job_title 
FROM employees;

3. UPDATE Operations (Update)
A. Single-Record Targeted Update
Promotes an employee to a senior grade and updates their compensation.
UPDATE employees
SET 
    job_title = 'Senior Full Stack Developer',
    salary = 105000.00
WHERE emp_id = 104;
B. Conditional Multi-Row Update
Gives an 8% annual inflation revision to all active employees working in department 10 (Engineering).
UPDATE employees
SET salary = ROUND(salary * 1.08, 2)
WHERE dept_id = 10 AND status = 'Active';
C. Safe Update Check
Tip: In MySQL Workbench, SQL_SAFE_UPDATES = 1 prevents running UPDATE without a WHERE clause containing a key column. Always include a primary or unique key in the WHERE condition.
