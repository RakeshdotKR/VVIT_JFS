Filtering & Sorting (WHERE, LIKE, IN, BETWEEN, ORDER BY, LIMIT) applied to the BharatTech_DB company schema.
________________________________________
1. Basic Filtering (WHERE with Logical AND, OR, NOT)
Filter High-Earning Engineers
Find active employees in the Engineering department (dept_id = 10) earning ₹1,00,000 or more per month.

SELECT 
    emp_id, 
    CONCAT(first_name, ' ', last_name) AS full_name, 
    job_title, 
    salary
FROM employees
WHERE dept_id = 10 
  AND salary >= 100000.00 
  AND status = 'Active';
________________________________________
2. Range Filtering (BETWEEN)
A. Numeric Salary Range
Retrieve employees whose monthly salary falls inclusively between ₹80,000 and ₹1,50,000.
SELECT 
    first_name, 
    last_name, 
    job_title, 
    salary
FROM employees
WHERE salary BETWEEN 80000.00 AND 150000.00;
B. Date Range Filtering
Find all team members onboarded during the calendar years 2021 and 2022.
SELECT 
    emp_id, 
    CONCAT(first_name, ' ', last_name) AS employee_name, 
    hire_date
FROM employees
WHERE hire_date BETWEEN '2021-01-01' AND '2022-12-31';
________________________________________
3. Set Membership Filtering (IN / NOT IN)
Filter Specific Departments
Retrieve employees belonging specifically to Engineering (10), Cloud Infrastructure (30), or Human Resources (50).
SELECT 
    emp_id, 
    first_name, 
    job_title, 
    dept_id
FROM employees
WHERE dept_id IN (10, 30, 50);
________________________________________
4. Pattern Matching (LIKE with Wildcards % and _)
•	% matches zero or more characters.
•	_ matches exactly one character.
A. Match Any Title Containing "Developer"
SELECT 
    emp_id, 
    CONCAT(first_name, ' ', last_name) AS developer_name, 
    job_title
FROM employees
WHERE job_title LIKE '%Developer%';
B. Match Specific Starting and Ending Patterns
Find all employees whose first name starts with the letter 'A' and ends with 'a' (e.g., Ananya).
SELECT 
    emp_id, 
    first_name, 
    email
FROM employees
WHERE first_name LIKE 'A%a';
________________________________________
5. Handling Missing Values (IS NULL / IS NOT NULL)
Find Top-Level Leadership (No Direct Manager Assigned)
SELECT 
    emp_id, 
    CONCAT(first_name, ' ', last_name) AS executive_name, 
    job_title
FROM employees
WHERE manager_id IS NULL;
________________________________________
6. Sorting Results (ORDER BY ASC / DESC)
Multi-Column Sorting
Sort employees primarily by Department ID ascending, and secondarily by Salary descending (highest paid within each department first).
SELECT 
    dept_id, 
    CONCAT(first_name, ' ', last_name) AS employee_name, 
    salary
FROM employees
ORDER BY dept_id ASC, salary DESC;
________________________________________
7. Limiting & Pagination (LIMIT & OFFSET)
A. Top 3 Highest Earners Across the Company
SELECT 
    emp_id, 
    CONCAT(first_name, ' ', last_name) AS employee_name, 
    job_title, 
    salary
FROM employees
ORDER BY salary DESC
LIMIT 3;
B. Pagination (Page 2: Skipping First 3 Records, Fetching Next 3)
SELECT 
    emp_id, 
    CONCAT(first_name, ' ', last_name) AS employee_name, 
    salary
FROM employees
ORDER BY salary DESC
LIMIT 3 OFFSET 3; -- Equivalent to: LIMIT 3, 3 in MySQL


GROUP BY & Aggregate Functions (COUNT, SUM, AVG, MIN, MAX, HAVING) applied to the BharatTech_DB schema.
________________________________________
1. Overall Company-Wide Aggregations
Computes company-level workforce metrics across all active employees without grouping.
SELECT 
    COUNT(*) AS total_headcount,
    COUNT(manager_id) AS total_managed_employees, -- Ignores NULL values
    SUM(salary) AS total_monthly_payroll,
    ROUND(AVG(salary), 2) AS company_average_salary,
    MIN(salary) AS lowest_salary,
    MAX(salary) AS highest_salary
FROM employees
WHERE status = 'Active';
________________________________________
2. Basic GROUP BY Aggregations
A. Department-Wise Payroll & Headcount Analysis
Groups employees by their department ID to calculate total expenditure and average compensation per division.
SELECT 
    dept_id,
    COUNT(*) AS total_employees,
    SUM(salary) AS dept_monthly_payroll,
    ROUND(AVG(salary), 2) AS dept_average_salary,
    MIN(salary) AS min_salary,
    MAX(salary) AS max_salary
FROM employees
GROUP BY dept_id
ORDER BY dept_monthly_payroll DESC;
B. Project-Wise Resource & Effort Summary
Aggregates total team members assigned and total weekly hours allocated per project from employee_projects.
SELECT 
    project_id,
    COUNT(emp_id) AS assigned_developers,
    SUM(hours_allocated) AS total_weekly_hours,
    ROUND(AVG(hours_allocated), 1) AS avg_hours_per_person
FROM employee_projects
GROUP BY project_id;
________________________________________
3. Multi-Column GROUP BY
Groups data by both Department and Job Title to identify headcount and compensation distribution across different job tiers.
SELECT 
    dept_id,
    job_title,
    COUNT(*) AS employee_count,
    ROUND(AVG(salary), 2) AS avg_role_salary
FROM employees
GROUP BY dept_id, job_title
ORDER BY dept_id ASC, avg_role_salary DESC;
________________________________________
4. Filtering Aggregated Groups using HAVING
Key Rule:
•	WHERE filters individual rows before aggregation takes place.
•	HAVING filters summary groups after aggregation has occurred.
A. Filter Departments with at least 2 Employees and High Average Pay
Find departments that have 2 or more team members and an average monthly salary exceeding ₹1,00,000.
SELECT 
    dept_id,
    COUNT(*) AS headcount,
    ROUND(AVG(salary), 2) AS average_salary,
    SUM(salary) AS total_cost
FROM employees
GROUP BY dept_id
HAVING COUNT(*) >= 2 
   AND AVG(salary) > 100000.00;
B. Combining WHERE, GROUP BY, HAVING, and ORDER BY
Find departments with active employees earning above ₹80,000, where the department's total payroll for such employees exceeds ₹1,50,000.
SELECT 
    dept_id,
    COUNT(*) AS qualified_headcount,
    SUM(salary) AS filtered_payroll
FROM employees
WHERE status = 'Active' AND salary >= 80000.00 -- Row-level filter
GROUP BY dept_id                               -- Grouping
HAVING SUM(salary) > 150000.00                 -- Aggregate-level filter
ORDER BY filtered_payroll DESC;                -- Final sorting

SQL Joins (INNER, LEFT, RIGHT, FULL OUTER, CROSS, and SELF JOIN) applied to the BharatTech_DB schema.
________________________________________
1. INNER JOIN (Matching Rows in Both Tables)
Retrieves only employees who are assigned to a valid department along with the department's city.
SELECT 
    e.emp_id,
    CONCAT(e.first_name, ' ', e.last_name) AS employee_name,
    e.job_title,
    d.dept_name,
    d.city AS office_location
FROM employees e
INNER JOIN departments d ON e.dept_id = d.dept_id;
________________________________________
2. LEFT JOIN (All Left Rows + Matching Right Rows)
Lists all departments, including those with zero employees (e.g., Finance & Payroll), replacing missing counts with 0.
SELECT 
    d.dept_id,
    d.dept_name,
    d.city,
    COUNT(e.emp_id) AS total_staff,
    COALESCE(SUM(e.salary), 0.00) AS total_payroll
FROM departments d
LEFT JOIN employees e ON d.dept_id = e.dept_id
GROUP BY d.dept_id, d.dept_name, d.city
ORDER BY total_staff DESC;
________________________________________
3. RIGHT JOIN (All Right Rows + Matching Left Rows)
Retrieves all departments from the right-hand table along with any matching employees.
SELECT 
    d.dept_name,
    CONCAT(e.first_name, ' ', e.last_name) AS employee_name,
    e.job_title
FROM employees e
RIGHT JOIN departments d ON e.dept_id = d.dept_id;
________________________________________
4. FULL OUTER JOIN (All Rows from Both Tables)
MySQL Note: MySQL does not have a native FULL OUTER JOIN keyword. It is achieved by combining a LEFT JOIN and a RIGHT JOIN with UNION.
-- Combines all employees (even without departments) and all departments (even without employees)
SELECT 
    e.emp_id,
    CONCAT(e.first_name, ' ', e.last_name) AS employee_name,
    d.dept_name,
    d.city
FROM employees e
LEFT JOIN departments d ON e.dept_id = d.dept_id

UNION

SELECT 
    e.emp_id,
    CONCAT(e.first_name, ' ', e.last_name) AS employee_name,
    d.dept_name,
    d.city
FROM employees e
RIGHT JOIN departments d ON e.dept_id = d.dept_id;
________________________________________
5. SELF JOIN (Joining a Table to Itself)
Matches each employee with their respective Reporting Manager using the manager_id self-referential foreign key.
SELECT 
    e.emp_id AS 'Emp ID',
    CONCAT(e.first_name, ' ', e.last_name) AS 'Employee Name',
    e.job_title AS 'Role',
    COALESCE(CONCAT(m.first_name, ' ', m.last_name), 'Top Executive / No Manager') AS 'Reporting Manager',
    m.job_title AS 'Manager Role'
FROM employees e
LEFT JOIN employees m ON e.manager_id = m.emp_id;
________________________________________
6. CROSS JOIN (Cartesian Product: $M \times N$ Combinations)
Generates every possible combination of employee and department location (useful for compliance audits or location matrix modeling).
SELECT 
    CONCAT(e.first_name, ' ', e.last_name) AS employee_name,
    d.city AS audit_location
FROM employees e
CROSS JOIN departments d
LIMIT 10; -- Restricted for sample display
________________________________________
7. Multi-Table Join ($M:N$ Many-to-Many Relationship)
Joins three tables (employees, employee_projects, and projects) to produce a complete project allocation sheet.
SELECT 
    CONCAT(e.first_name, ' ', e.last_name) AS employee_name,
    p.project_name,
    ep.assigned_role,
    ep.hours_allocated AS weekly_hours,
    p.budget AS project_total_budget
FROM employees e
INNER JOIN employee_projects ep ON e.emp_id = ep.emp_id
INNER JOIN projects p ON ep.project_id = p.project_id
ORDER BY p.project_name ASC, ep.hours_allocated DESC;

: Subqueries (Scalar, Multi-Row, Correlated, and EXISTS / NOT EXISTS) applied to the BharatTech_DB schema.
________________________________________
1. Scalar Subqueries (Returns Exactly 1 Row and 1 Column)
A. Scalar Subquery in WHERE Clause
Finds all employees who earn strictly more than the overall company average salary.
SELECT 
    emp_id,
    CONCAT(first_name, ' ', last_name) AS employee_name,
    job_title,
    salary
FROM employees
WHERE salary > (
    -- Inner Scalar Query: Evaluates to a single decimal value
    SELECT AVG(salary) 
    FROM employees
)
ORDER BY salary DESC;
B. Scalar Subquery in SELECT Projection
Displays each employee alongside the company's highest salary and their difference from the maximum.
SELECT 
    CONCAT(first_name, ' ', last_name) AS employee_name,
    salary,
    (SELECT MAX(salary) FROM employees) AS company_max_salary,
    ROUND((SELECT MAX(salary) FROM employees) - salary, 2) AS gap_from_top
FROM employees;
________________________________________
2. Multi-Row Subqueries (IN, ANY, ALL)
A. Multi-Row Subquery with IN
Finds employees working in departments situated in the tech hub of Bengaluru.
SELECT 
    emp_id,
    CONCAT(first_name, ' ', last_name) AS employee_name,
    job_title
FROM employees
WHERE dept_id IN (
    -- Returns a list: (10, ...)
    SELECT dept_id 
    FROM departments 
    WHERE city = 'Bengaluru'
);
B. Multi-Row Subquery with > ALL
Finds employees whose salary is strictly greater than every employee's salary in the Product Management department (dept_id = 20).
SELECT 
    emp_id,
    CONCAT(first_name, ' ', last_name) AS employee_name,
    salary
FROM employees
WHERE salary > ALL (
    SELECT salary 
    FROM employees 
    WHERE dept_id = 20
);
________________________________________
3. Correlated Subqueries (Evaluated Row-by-Row)
In a correlated subquery, the inner query references columns from the outer query (e.dept_id). It re-executes for every row processed by the outer query.
Find Employees Earning Above Their Own Department's Average
SELECT 
    e.emp_id,
    CONCAT(e.first_name, ' ', e.last_name) AS employee_name,
    e.job_title,
    e.salary,
    e.dept_id
FROM employees e
WHERE e.salary > (
    -- Re-calculates average specifically for the outer row's department
    SELECT AVG(sub.salary)
    FROM employees sub
    WHERE sub.dept_id = e.dept_id
);
________________________________________
4. EXISTS & NOT EXISTS Operators
EXISTS tests for the presence of matching records and terminates evaluation as soon as the first match is found (more performant than IN for large datasets).
A. EXISTS: Find Departments That Have at Least One Project Assigned
SELECT 
    d.dept_id,
    d.dept_name,
    d.city
FROM departments d
WHERE EXISTS (
    SELECT 1 
    FROM projects p 
    WHERE p.dept_id = d.dept_id
);
B. NOT EXISTS: Find Employees Not Allocated to Any Project
Identifies unallocated/bench talent across the organization.
SELECT 
    e.emp_id,
    CONCAT(e.first_name, ' ', e.last_name) AS bench_employee,
    e.job_title
FROM employees e
WHERE NOT EXISTS (
    SELECT 1 
    FROM employee_projects ep 
    WHERE ep.emp_id = e.emp_id
);
________________________________________
5. Subqueries in the FROM Clause (Derived Tables)
Treats the result of an inner SELECT query as a temporary table (an alias is mandatory in MySQL).
-- Calculate the average departmental payroll across the company
SELECT 
    ROUND(AVG(dept_summary.total_dept_payroll), 2) AS avg_payroll_across_depts
FROM (
    SELECT 
        dept_id, 
        SUM(salary) AS total_dept_payroll
    FROM employees
    GROUP BY dept_id
) AS dept_summary;
