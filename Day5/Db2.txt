Filtering & Sorting (WHERE, LIKE, IN, BETWEEN, ORDER BY, LIMIT) applied to the BharatTech_DB company schema.
________________________________________
1. Basic Filtering (WHERE with Logical AND, OR, NOT)
Filter High-Earning Engineers
Find active employees in the Engineering department (dept_id = 10) earning ₹1,00,000 or more per month.

SELECT 
    emp_id, 
    CONCAT(first_name, ' ', last_name) AS full_name, 
    job_title, 
    salary
FROM employees
WHERE dept_id = 10 
  AND salary >= 100000.00 
  AND status = 'Active';
________________________________________
2. Range Filtering (BETWEEN)
A. Numeric Salary Range
Retrieve employees whose monthly salary falls inclusively between ₹80,000 and ₹1,50,000.
SELECT 
    first_name, 
    last_name, 
    job_title, 
    salary
FROM employees
WHERE salary BETWEEN 80000.00 AND 150000.00;
B. Date Range Filtering
Find all team members onboarded during the calendar years 2021 and 2022.
SELECT 
    emp_id, 
    CONCAT(first_name, ' ', last_name) AS employee_name, 
    hire_date
FROM employees
WHERE hire_date BETWEEN '2021-01-01' AND '2022-12-31';
________________________________________
3. Set Membership Filtering (IN / NOT IN)
Filter Specific Departments
Retrieve employees belonging specifically to Engineering (10), Cloud Infrastructure (30), or Human Resources (50).
SELECT 
    emp_id, 
    first_name, 
    job_title, 
    dept_id
FROM employees
WHERE dept_id IN (10, 30, 50);
________________________________________
4. Pattern Matching (LIKE with Wildcards % and _)
•	% matches zero or more characters.
•	_ matches exactly one character.
A. Match Any Title Containing "Developer"
SELECT 
    emp_id, 
    CONCAT(first_name, ' ', last_name) AS developer_name, 
    job_title
FROM employees
WHERE job_title LIKE '%Developer%';
B. Match Specific Starting and Ending Patterns
Find all employees whose first name starts with the letter 'A' and ends with 'a' (e.g., Ananya).
SELECT 
    emp_id, 
    first_name, 
    email
FROM employees
WHERE first_name LIKE 'A%a';
________________________________________
5. Handling Missing Values (IS NULL / IS NOT NULL)
Find Top-Level Leadership (No Direct Manager Assigned)
SELECT 
    emp_id, 
    CONCAT(first_name, ' ', last_name) AS executive_name, 
    job_title
FROM employees
WHERE manager_id IS NULL;
________________________________________
6. Sorting Results (ORDER BY ASC / DESC)
Multi-Column Sorting
Sort employees primarily by Department ID ascending, and secondarily by Salary descending (highest paid within each department first).
SELECT 
    dept_id, 
    CONCAT(first_name, ' ', last_name) AS employee_name, 
    salary
FROM employees
ORDER BY dept_id ASC, salary DESC;
________________________________________
7. Limiting & Pagination (LIMIT & OFFSET)
A. Top 3 Highest Earners Across the Company
SELECT 
    emp_id, 
    CONCAT(first_name, ' ', last_name) AS employee_name, 
    job_title, 
    salary
FROM employees
ORDER BY salary DESC
LIMIT 3;
B. Pagination (Page 2: Skipping First 3 Records, Fetching Next 3)
SELECT 
    emp_id, 
    CONCAT(first_name, ' ', last_name) AS employee_name, 
    salary
FROM employees
ORDER BY salary DESC
LIMIT 3 OFFSET 3; -- Equivalent to: LIMIT 3, 3 in MySQL


GROUP BY & Aggregate Functions (COUNT, SUM, AVG, MIN, MAX, HAVING) applied to the BharatTech_DB schema.
________________________________________
1. Overall Company-Wide Aggregations
Computes company-level workforce metrics across all active employees without grouping.
SELECT 
    COUNT(*) AS total_headcount,
    COUNT(manager_id) AS total_managed_employees, -- Ignores NULL values
    SUM(salary) AS total_monthly_payroll,
    ROUND(AVG(salary), 2) AS company_average_salary,
    MIN(salary) AS lowest_salary,
    MAX(salary) AS highest_salary
FROM employees
WHERE status = 'Active';
________________________________________
2. Basic GROUP BY Aggregations
A. Department-Wise Payroll & Headcount Analysis
Groups employees by their department ID to calculate total expenditure and average compensation per division.
SELECT 
    dept_id,
    COUNT(*) AS total_employees,
    SUM(salary) AS dept_monthly_payroll,
    ROUND(AVG(salary), 2) AS dept_average_salary,
    MIN(salary) AS min_salary,
    MAX(salary) AS max_salary
FROM employees
GROUP BY dept_id
ORDER BY dept_monthly_payroll DESC;
B. Project-Wise Resource & Effort Summary
Aggregates total team members assigned and total weekly hours allocated per project from employee_projects.
SELECT 
    project_id,
    COUNT(emp_id) AS assigned_developers,
    SUM(hours_allocated) AS total_weekly_hours,
    ROUND(AVG(hours_allocated), 1) AS avg_hours_per_person
FROM employee_projects
GROUP BY project_id;
________________________________________
3. Multi-Column GROUP BY
Groups data by both Department and Job Title to identify headcount and compensation distribution across different job tiers.
SELECT 
    dept_id,
    job_title,
    COUNT(*) AS employee_count,
    ROUND(AVG(salary), 2) AS avg_role_salary
FROM employees
GROUP BY dept_id, job_title
ORDER BY dept_id ASC, avg_role_salary DESC;
________________________________________
4. Filtering Aggregated Groups using HAVING
Key Rule:
•	WHERE filters individual rows before aggregation takes place.
•	HAVING filters summary groups after aggregation has occurred.
A. Filter Departments with at least 2 Employees and High Average Pay
Find departments that have 2 or more team members and an average monthly salary exceeding ₹1,00,000.
SELECT 
    dept_id,
    COUNT(*) AS headcount,
    ROUND(AVG(salary), 2) AS average_salary,
    SUM(salary) AS total_cost
FROM employees
GROUP BY dept_id
HAVING COUNT(*) >= 2 
   AND AVG(salary) > 100000.00;
B. Combining WHERE, GROUP BY, HAVING, and ORDER BY
Find departments with active employees earning above ₹80,000, where the department's total payroll for such employees exceeds ₹1,50,000.
SELECT 
    dept_id,
    COUNT(*) AS qualified_headcount,
    SUM(salary) AS filtered_payroll
FROM employees
WHERE status = 'Active' AND salary >= 80000.00 -- Row-level filter
GROUP BY dept_id                               -- Grouping
HAVING SUM(salary) > 150000.00                 -- Aggregate-level filter
ORDER BY filtered_payroll DESC;                -- Final sorting
